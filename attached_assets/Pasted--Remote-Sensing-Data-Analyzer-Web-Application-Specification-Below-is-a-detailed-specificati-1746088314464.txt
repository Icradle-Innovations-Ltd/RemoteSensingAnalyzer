# 🌍 Remote Sensing Data Analyzer — Web Application Specification

Below is a detailed specification for building the **Remote Sensing Data Analyzer with Frequency-Domain Filtering**, a user-friendly web application designed for environmental scientists, GIS analysts, and developers to process and analyze satellite imagery using frequency-domain techniques.

---

## 📌 Project Title
**Remote Sensing Data Analyzer with Frequency-Domain Filtering**  
*Effortless frequency-based feature extraction for satellite imagery*

---

## 🎯 Objective

### Primary Objective
Develop a web application that enables users to:
- **Upload** satellite imagery in various formats (JPG, PNG, GeoTIFF).
- **Visualize** the frequency-domain representation of images using Fourier Transforms.
- **Apply** customizable frequency filters (low-pass, high-pass, band-stop) to highlight or suppress spatial features.
- **Compare** original and processed images side-by-side.
- **Download** filtered images for further analysis or reporting.

### Secondary Objectives
- Provide advanced tools such as NDVI computation, texture-based classification, and geo-referenced overlays.
- Optimize performance for handling large image datasets.
- Deliver a smooth, interactive user experience with real-time filter previews.

By completing this project, users will understand how spatial textures (e.g., smooth water surfaces or urban structures) relate to specific frequency bands, enhancing their ability to analyze remote sensing data.

## 🔬 Detailed Workflow

### 1. Image Upload & Preprocessing
- **Input**: User uploads an image via Streamlit’s file uploader.
- **Processing**:
  - **JPG/PNG**: Loaded as RGB or grayscale; converted to grayscale if multi-channel.
  - **GeoTIFF**: Read using `rasterio`; if multi-band, offer band selection (e.g., Red, NIR).
  - **Resize**: Optionally downscale large images (e.g., >1024×1024) for performance.

### 2. Frequency-Domain Conversion
- **Steps**:
  1. Compute 2D FFT with `np.fft.fft2(img_array)` to get a complex frequency matrix.
  2. Shift zero-frequency component to center using `np.fft.fftshift()`.
  3. Calculate magnitude spectrum: `20 * np.log10(np.abs(fft_shifted) + 1)` for visualization.
- **Output**: Display log-scaled spectrum as a heatmap using Matplotlib.

### 3. Filter Mask Creation
- **Low-Pass Filter**: Circular mask retaining frequencies within radius *R_low*.
- **High-Pass Filter**: Inverse of low-pass, retaining frequencies beyond radius *R_high*.
- **Band-Stop Filter**: Ring-shaped mask excluding frequencies between *R1* and *R2*.
- **Enhancement**: Option to apply Gaussian tapering to reduce ringing artifacts.

### 4. Applying Filters & Inverse Transform
- **Process**:
  1. Multiply FFT with mask: `fft_shifted * mask`.
  2. Inverse shift: `np.fft.ifftshift(filtered_fft)`.
  3. Perform inverse FFT: `np.fft.ifft2()` to return to spatial domain.
  4. Extract real part and normalize to 0–255 range (e.g., using `skimage.exposure.rescale_intensity`).
- **Output**: Filtered image as `uint8` for display and export.

### 5. UI & Interaction
- **Sidebar**:
  - File uploader.
  - Band selector (for GeoTIFF).
  - Filter type (radio buttons: Low-pass, High-pass, Band-stop).
  - Sliders for cutoff radii (e.g., single radius for low/high-pass, two for band-stop).
  - Checkbox for Gaussian smoothing.
- **Main Panel**:
  - Three columns: Original Image, FFT Spectrum, Filtered Image.
  - Download button for filtered output.

## 📈 Deployment & Testing
- **Local Run**: `streamlit run app.py`.
- **Docker**:
  ```dockerfile
  FROM python:3.10-slim
  WORKDIR /app
  COPY . /app
  RUN pip install --no-cache-dir -r requirements.txt
  EXPOSE 8501
  ENTRYPOINT ["streamlit", "run", "app.py", "--server.port=8501", "--server.address=0.0.0.0"]
  ```
- **Cloud Deployment**: Use Streamlit Cloud or Render.com with GitHub integration.

### Testing
- **Unit Tests** (in `tests/`):
  - Verify filter mask shapes and values.
  - Ensure FFT/IFFT pipeline preserves image integrity.
  - Test edge cases (e.g., small images, invalid uploads).

## 📖 Developer Notes
- **Large Images**: Use `rasterio` windowed reading for >4096×4096 images.
- **Performance**: Cache FFT in Streamlit’s session state to avoid recomputation.
- **Responsiveness**: Debounce slider updates or apply filters on button click.
- **Modularity**: Keep advanced features in `modules/` for easy extension.
